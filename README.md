# Kickverse ⚽

Футбольная игра с карточками футболистов: открывай паки, собирай состав, выигрывай матчи.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес из терминала (обычно http://localhost:5173). Работает на компьютере (клавиатура) и на планшете (кнопки на экране).

## Как играть

- **PLAY** — начать матч (2 тайма по 90 секунд). Команда собирается из твоих карточек.
- **Паки** — бронзовый (300), серебряный (800), золотой (2000 монет). При открытии сначала показывается страна, потом позиция, клуб и сам футболист.
- **Мой состав** — расставь игроков по схеме 4-3-3 или нажми «Автосостав».
- Награда за матч: победа 500, ничья 250, поражение 100 монет.

## Управление в матче

| Действие | Клавиатура | Экран |
|---|---|---|
| Движение | Стрелки / WASD | Крестовина слева |
| Пас | J (или Z) | ПАС |
| Удар | K (или X) | УДАР |
| Дриблинг | L (или C) | ДРИБЛИНГ |
| Спринт | Shift / Пробел | СПРИНТ |
| Выйти из матча | Esc | — |

Комментатор озвучивает игроков голосом браузера (Web Speech API), его можно выключить в меню. Прогресс сохраняется в браузере.
